02 / ACCESS

入口与权限

默认只开放固定命令，群聊仅管理员可用。生图、查看或切换角色卡、切换 NAI 模型都会经过同一套命令入口与权限检查。

i
安全默认值

固定命令和自主调用可以四选一；群聊策略默认管理员；每条消息最多返回一张图片，只有明确启用时才会对 429 限流进行有限重试。

03 / STICKER MODE

表情包模式

LLM 回复完成后，插件结合上下文、情绪标签和表情包角色卡判断是否生成当前情绪表情包。默认关闭，不影响普通聊天和普通生图。

i
触发链路

先按概率抽样，再由判断模型选择是否发送。表情包生成失败会静默降级为原文字回复；“同一气泡”模式会自动使用非流式回复以保证文字和图片一起发送。

专用角色卡

独立于普通角色卡，只用于表情包生成。建议填写固定人物主体、画风、服装和禁止项。

04 / REFERENCE

参考图与图生图

官方 NovelAI 后端支持图生图和 Precise Reference。先上传图片，再绑定到角色卡；OpenAI 兼容后端使用标准 images/edits，参考图增强能力由上游决定。

!
Precise Reference 提示

参考图会增加服务消耗；Strength 越高越贴近参考图，Fidelity 越高越难被提示词覆盖。多张人物参考图可能被融合为一个角色。
